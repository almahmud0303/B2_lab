**All guides use MAIN branch only!**

```bash
# You'll work like this:

# ... work and commit ...
git checkout main                    # Back to main
```

# 💡 **PRO TIPS**

## **Development Tips:**

1. **Commit Often**
   - Every 30-60 minutes
   - After each feature
   - Before risky changes

2. **Test Immediately**
   - After each step
   - Don't build everything then test
   - Fix bugs as you find them

3. **Read Error Messages**
   - They tell you exactly what's wrong
   - Don't ignore them
   - Google if unclear

4. **Use Tinker**
   - Test queries before using in code
   - Check data in database
   - Debug issues

5. **Follow Patterns**
   - Days 1-9 show the pattern
   - Repeat for Days 10-20
   - Consistency is key

---

## **Learning Tips:**

1. **Understand, Don't Just Copy**
   - Read code before copying
   - Understand why it works
   - Can explain if asked

2. **Take Breaks**
   - Don't code 8 hours straight
   - Fresh mind solves problems faster

3. **Document as You Go**
   - Write notes
   - Explain in your own words
   - Helps in interviews

4. **Practice Explaining**
   - Explain code out loud
   - Pretend you're teaching someone
   - Builds confidence

# 📞 **EMERGENCY QUICK FIXES**

## **Can't Install Laravel:**
```bash
# Check PHP version
php --version  # Need 8.2+

# Update Composer
composer self-update

# Try specific version
composer create-project laravel/laravel . "11.*"
```

## **Can't Run Server:**
```bash
# Different port
php artisan serve --port=8001

# Check if running
netstat -ano | findstr :8000
```

## **Database Error:**
```bash
# Use SQLite (easier)
# In .env:
DB_CONNECTION=sqlite

# Create database:
touch database/database.sqlite

# Run migrations:
php artisan migrate
```

## **Login Not Working:**
```bash
# Reset admin password
php artisan tinker
>>> $user = User::where('email', 'admin@kuet.ac.bd')->first()
>>> $user->update(['password' => Hash::make('password')])
>>> exit
```
